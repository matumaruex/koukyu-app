# 公休表アプリ

介護施設の公休表をスマホで作成・編集するアプリです。対象期間は毎月16日から翌月15日まで。職員・希望・前期の勤務を入力し、作成した表で人数不足や勤務条件の例外を確認できます。作業中の表は端末に自動保存され、名前を付けた控えの保存、横画面での確認、印刷ができます。[公開版](https://koukyu-app.vercel.app/)

## 開発を始める

- **PCでアプリを試す**　Windowsではリポジトリ直下の `アプリ起動.ps1` をPowerShellで実行すると、ブラウザで `http://127.0.0.1:8766/` が開きます。計算はPC上で行い、入力と表はそのブラウザに保存します。公開版とのデータ移動には「設定・データ」の書き出し・読み込みを使います。[起動スクリプト](アプリ起動.ps1)
- **コードを変更・検証する**　Python 3.12とNode.jsを使います。依存関係の準備、ローカル起動、Python・画面テストのコマンドは開発手順にあります。[開発手順](solver/README.md#開発とテスト)
- **変更箇所を探す**　画面と入力は `public/mobile.js`、保存・移行は `public/roster-storage.js`、計算の入口は `solver/service.py`、勤務の探索は `solver/engine.py`、完成表の独立検査は `solver/validator.py` です。[画面](public/) · [API](api/) · [計算と検査](solver/)
